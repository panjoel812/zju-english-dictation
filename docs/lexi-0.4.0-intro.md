# ZED 更新了：英语和六种小语种，都可以按单元默写

ZED 是 ZJU English Dictation 的缩写，也就是浙江大学英语默写器。

它是一个按课程和单元练习单词的小工具：选好词库，对照中文、听发音，在页面上输入拼写，再按 Enter 检查。电脑和手机都可以使用，不需要注册。

这次 0.4.0 新增了德语、西班牙语、法语、日语、韩语和俄语，共 7,914 条词条、125 个单元。原来的大学英语 III、IV、Book 1 和新工科英语词库也都保留。进入词库页，先选择语言，再选择资料中的 B 编号和 Unit，就能找到对应的词条。

小语种统一使用整词提交，可以使用系统输入法；德、西、法语还提供特殊字符按钮。日语词条明确标注了假名和汉字时，两种写法都可以提交。小语种朗读使用设备里的对应语言语音包。

练习页面也调整了一些细节：默认显示中文、隐藏字母数，默写时隐藏音标；需要提示时可以开启首字母，或者点击中文下方的「查看答案」。释义开关和显示设置会自动记住，下次进入继续使用自己的选择。

第一次打开会逐项介绍功能，之后也可以点击左下角的问号重新查看。练习记录保存在当前浏览器中，需要换设备时，先通过顶部下载图标导出备份，再在新设备的「设置 → 数据管理」里导入。
