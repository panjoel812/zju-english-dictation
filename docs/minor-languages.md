# 小语种课程词库

v0.4.0 从用户提供的「小语种课程单词默写器（德语:西语:法语:日语:韩语:俄语）.zip」导入六种语言。该压缩包只有数据和清单，不包含可执行代码。

| 语言     |  词条 | 单元 | 来源分组                   |
| -------- | ----: | ---: | -------------------------- |
| 德语     | 3,277 |   40 | B1–B4，各 Unit 1–10        |
| 西班牙语 |   656 |   10 | B1，Unit 1–10              |
| 法语     |   433 |    8 | B1，Unit 1–8               |
| 日语     | 2,112 |   48 | B1，Unit 1–48              |
| 韩语     | 1,060 |   10 | B1，Unit 1–10              |
| 俄语     |   376 |    9 | B1，Unit 2–7、9–11         |
| 合计     | 7,914 |  125 | 按源文件计数，不跨单元去重 |

保留源文件的 B 编号，不把它解释成欧洲语言等级。俄语源文件没有 Unit 1、8，页面不生成空单元。词库页先选择语言，再选择 B 编号和单元；每个单元继续按原有每章 20 词拆分。

词条及中文释义按原文导入，原有 tags 中的词性加在释义前，保留原始 ID、释义、tags、sourceSheet 和 notes 以便核对。不推断缺失词性，也不补写翻译。法语 notes 中明确标注的音标另存为 phonetic，只在关闭默写且开启音标时展示。

日语只有明确符合「假名（汉字）」格式的词条才增加两种可接受写法，完整原文仍保留且同样可提交。答案比较采用 Unicode NFC 标准化，兼容预组合与组合重音字符；不删除重音，不把不同字母视为相同。

小语种固定使用整词提交，输入法组合期间的 Enter 不判分；这不会覆盖英语原有的整词/逐字选择。德、西、法语可以展开特殊字符键盘，在光标处插入字符。日、韩、俄语使用系统输入法。首字母提示支持 Unicode 字母。

小语种朗读使用浏览器 SpeechSynthesis，并指定清单中的 de-DE、es-ES、fr-FR、ja-JP、ko-KR、ru-RU。声音和可用性取决于设备安装的语音包；英语继续使用原有发音来源。

复现导入或逐条核对：

```sh
python3 scripts/import-minor-languages.py '/path/to/archive.zip'
python3 scripts/import-minor-languages.py '/path/to/archive.zip' --check
npm run test:languages
```

数据保留原资料中的用词和注记；课程资料的权利归原权利人所有。导入不会改动现有英语词库 ID、浏览器记录、释义 cookie 或主题偏好。
