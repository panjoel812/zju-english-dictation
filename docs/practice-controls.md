# 导航与设置

顶部沿用图标形式，按「释义、单词列表、错题本、统计、导出、主题、指法」排列，最后是开始/暂停和设置。释义与深色模式只在顶部切换；导出只使用顶部下载图标。

设置按内容分为四类，每项参数只有一处控件：

- 默写设置：默写开关、隐藏方式、隐藏长度、判定方式、循环次数、乱序、大小写与悬停提示。
- 发音音效：自动发音、口音、循环朗读、音量、倍速、中文朗读、按键与答题音效。
- 显示设置：音标、相邻词、文本选择和字号。
- 数据管理：备份使用说明与导入。导出文件仍使用现有 Dexie gzip 格式，可供现有导入功能读取。

首次使用默认显示中文释义，并开启「隐藏字母数」，以固定长度横线输入完整英文。已有的中文 cookie 和字母数手动设置优先，不会因默认值更新而被覆盖。

主题启动脚本与应用共同读取 `isOpenDarkModeAtom`；没有设置时跟随系统。根节点的 `color-scheme` 同步明暗主题，使原生控件保持一致。设置 CSS 模块使用 `:global(.dark)` 匹配根主题，避免暗色选择器被局部化；内部类名也避开 `block` 等 Tailwind 工具类名称。

「显示首字母」位于默写设置，默认关闭，使用 `showFirstLetter` 本地存储记住选择。开启后，字母格保留词条第一个英文字母；隐藏字母数时单独显示一个首字母提示，不暴露词长。前导标点不计作首字母，短语只提示词条开头的字母。提示不会预填输入或自动判对，仍需输入完整拼写。

默写模式下始终隐藏音标，包括暂停、输入、答错和查看答案时；已有的「显示音标」偏好不影响这条规则。关闭默写后才按该偏好显示音标，切换模式不会改写偏好。

首次访问练习页会启动 13 步功能介绍，逐项标出词表、练习区和顶部工具。完成、跳过或关闭后，通过 `zju-practice-guide-seen-v1` 本地存储记住状态，无法写入时使用会话存储和当前页面状态。新访客先看功能介绍，避免和更新说明同时弹出；更新说明始终可以从设置打开。左下角问号可重新开始介绍，查看时暂停练习、保留输入，并隔离背景快捷键。支持上一步、下一步、左右方向键和 Escape 关闭。

释义开关使用 `zju-translation-visible` cookie，保存一年，路径 `/`、SameSite=Lax；HTTPS 时设置 Secure。未设置或浏览器禁止 cookie 时默认开启，已保存的关闭选择会继续生效。

「查看答案」只展开当前词的拼写和释义，不改动输入、不提交、不计为答对；切词或循环重练后收起。打开指法或设置会暂停练习，弹窗在输入区域之上。

# 词性补充

运行 `node scripts/complete-zju-pos.mjs` 可重现补充过程。候选来自项目现有词典，以释义中的词义和已有词性匹配；多义词、短语及局部词典标注不适用于课程释义的条目，按课程释义逐项列于 `scripts/data/zju-pos-overrides.json`。保留原有前缀、末尾词性及原文注记，不用词尾规则推断词性。

共增加 1,165 个前缀，涉及英语 III、IV、Book 1 的 25 份词表。新工科已有词性；Book 1 原有末尾词性保留。词条名称、顺序、原释义与音标不变；原本没有释义的四个英语 IV 条目不在补充范围。测试核对移除新增词性后的全部原始数据摘要，确保只补充标签。

- `npm run test:engineering`：原始词表完整性与词性覆盖。
- `npm run test:book1`：Book 1 词表完整性。
